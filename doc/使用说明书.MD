# U盘备份工具 - 使用说明

## 简介

本工具用于自动备份 U 盘中的照片、视频等文件到电脑。支持按文件类型自动分类存储，支持增量备份（只备份新文件），支持备份完成后安全弹出 U 盘。

## 首次使用

程序解压后，先创建配置文件：

1. 在程序目录找到 `config.example.ini`，复制一份并重命名为 `config.ini`
2. 用记事本打开 `config.ini`，按注释修改以下内容：
   - `suffix`：要备份的文件类型（如 `jpg, jpeg, mov, mp4`）
   - `backup_type`：操作类型（`copy` = 复制，`move` = 移动，`delete` = 删除）
   - `backup_path`：备份目标路径（如 `D:\Backup\Photos` 或 `%USERPROFILE%\Pictures`）
3. 保存后双击 `U盘备份工具.exe` 启动程序

详细字段说明见 `config.example.ini` 中的注释。

## 使用流程

### 一键备份所有 U 盘

1. 插入 U 盘（支持同时插入多个）
2. 启动程序，主菜单会显示已插入的 U 盘列表
3. 首次使用某个 U 盘需选择「初始化所有U盘数据库」
4. 选择「扫描所有U盘文件」
5. 选择「备份所有U盘文件」
6. 如配置了 `every_time` 规则，会提示输入自定义名称（可直接回车跳过）
7. 等待备份完成，选择「弹出所有U盘」安全移除

### 备份单个 U 盘

1. 在主菜单中选择要操作的 U 盘盘符（如 `F:\`）
2. 选择「扫描文件」
3. 选择「备份文件」
4. 完成后选择「弹出U盘」或「返回主菜单」

## 主菜单说明

| 选项 | 说明 |
|------|------|
| 重新检测U盘 | 刷新 U 盘列表，热插拔后使用 |
| 初始化所有U盘数据库 | 首次使用某个 U 盘前需初始化（记录文件信息） |
| 扫描所有U盘文件 | 扫描 U 盘中的文件，识别需要备份的新文件 |
| 备份所有U盘文件 | 按配置策略处理所有 U 盘中的文件 |
| 弹出所有U盘 | 安全弹出全部 U 盘，完成后可直接拔出 |
| 显示当前配置 | 查看当前生效的备份策略 |
| 检测目标路径是否存在 | 检查备份目标文件夹是否存在，不存在可自动创建 |

## 备份策略说明

每条策略由四个字段组成：

- `suffix`：文件后缀名，多个用逗号分隔（如 `jpg, jpeg`）
- `backup_type`：`copy`（复制，保留原文件）、`move`（移动，删除原文件）、`delete`（直接删除）
- `backup_path`：目标路径（支持 `%USERPROFILE%` 和 `~`），`delete` 类型不需要
- `target_sub_folder_name_rule`（可选）：
  - `every_day`：按文件修改日期自动建子文件夹（如 `2026.09.18`）
  - `every_time`：按备份批次建子文件夹（如 `2026.09.15-18 旅行`）
  - 留空：直接放入目标路径根目录

## 常见问题

**Q: 启动后提示"未找到有效的配置"**

A: 检查程序目录下是否有 `config.ini`，并确认内容格式正确。可参考 `config.example.ini`。

**Q: 备份时提示目标路径不存在**

A: 选择菜单中的「检测目标路径是否存在」，程序会提示是否自动创建。

**Q: 同一个 U 盘备份过一次后，再次备份会重复吗？**

A: 不会。复制类型的文件只处理新增文件，已备份的文件会被跳过。

**Q: U 盘里的文件被误删了怎么办？**

A: 使用 `copy` 类型的策略时，原文件会保留在 U 盘中；如果用的是 `move`，文件已移动到备份路径。
